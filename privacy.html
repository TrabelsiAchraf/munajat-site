Munajat — Privacy Policy

Last updated: May 13, 2026

Munajat ("the app") is a native iOS application that displays the adhkar from Hisn al-Muslim by Sheikh Saʿīd al-Qaḥṭānī. This Privacy Policy explains how the app handles data.

Data Collection

Munajat does not collect any personal data. The app has no user account, does not connect to any backend, does not include analytics, and does not include advertising or tracking SDKs.

Locally Stored Data

The following data is stored exclusively on your device and never leaves it:

  • Per-dhikr counters (reset at the start of each day)
  • Favorite categories
  • Notification time preferences (morning, evening, sleep)
  • Daily streak history (which days you read at least one dhikr)

This data is stored in iOS's standard local storage (UserDefaults and SwiftData) inside the app's sandbox. Uninstalling the app removes all of it.

Network Activity

The only network use is the optional audio recitation playback. When you tap Listen on a dhikr, the app streams the audio file from hisnmuslim.com. No identifier, account or analytics token is sent with the request — only the standard HTTP headers your iOS device produces for any web download. If you never tap Listen, the app makes no network requests at all.

Notifications

Reminders for morning, evening and sleep adhkar are scheduled locally by iOS using the standard UserNotifications framework. They never pass through any server.

Third-Party Services

Munajat does not use any third-party SDK, framework or service that collects data. The only external dependency is the audio CDN at hisnmuslim.com (above), which the app contacts only on explicit user action.

Children's Privacy

Munajat does not knowingly collect any data from children or anyone else.

Changes to This Policy
